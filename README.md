# Memory Game (Processing)

A small tile-matching memory game written in **Processing**, and my first GitHub commit.

- A 3×4 grid of face-down tiles is shuffled at the start.
- Click two tiles to flip them. Matching pairs stay open.
- Clear the whole board to win.

## Run

Install [Processing](https://processing.org/download), paste the contents of `Memory game` into a new sketch, then press **Run**.
